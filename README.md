# Telegram Video Downloader Bot

Un bot Telegram qui télécharge et compresse les vidéos via `yt_dlp` et `ffmpeg`.

## Fonctionnalités
- Vérifie l'abonnement à des chaînes
- Télécharge des vidéos à partir d’un lien
- Compresse les vidéos > 50 Mo

## Dépendances
- Python 3
- yt_dlp
- ffmpeg
- pyTelegramBotAPI (telebot)
